# Peek Guard

노트북 웹캠으로 **내 화면 쪽을 보는 얼굴 수**를 세어 Windows 작업 표시줄(트레이) 아이콘으로 알려 주는 작은 도구입니다.
다른 사람이 같이 보고 있으면 아이콘이 빨갛게 바뀌고 Windows 알림이 뜹니다.

- 영상은 저장하지 않고 얼굴 수만 셉니다. 네트워크는 처음 실행할 때 얼굴 모델을 내려받을 때만 씁니다.
- 기본값은 10초마다 카메라를 1~2초만 켜서 확인하는 방식이라 카메라 LED가 계속 켜져 있지 않습니다.
- 창 없이 백그라운드에서 돕니다.

## 아이콘

| 아이콘 | 뜻 |
|---|---|
| 🟢 1 | 1명이 보는 중(보통 나) |
| 🔴 2+ | 다른 사람도 보는 중. Windows 알림이 뜹니다 |
| ⚪ 0 | 화면을 보는 사람 없음 |
| ⚪ II | 일시정지(카메라 꺼짐) |
| ⚫ ! | 카메라를 쓸 수 없거나 오류로 멈춤(아이콘에 마우스를 올리면 이유가 보임) |

## 설치와 실행

Windows 10/11, Python 3.10 이상(3.12에서 확인)이 필요합니다.

```bash
pip install -r requirements.txt
```

`start.bat`을 더블클릭하면 콘솔 창 없이 실행됩니다(`pythonw peek_guard.py`와 같습니다).

- 처음 실행할 때 OpenCV 공식 저장소([opencv_zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet))에서 얼굴 모델 `face_detection_yunet_2023mar.onnx`(약 230KB)를 같은 폴더에 내려받습니다.
- 트레이 아이콘이 작업 표시줄의 `^`(숨겨진 아이콘) 안에 있으면 작업 표시줄로 끌어 놓으면 항상 보입니다.
- 부팅할 때 자동으로 켜려면 `Win+R` → `shell:startup`을 열고 그 폴더에 `start.bat` 바로가기를 넣습니다.

## 메뉴(아이콘 우클릭)

- **카메라 화면 보기**: 얼굴 박스와 방향 수치를 보여 줍니다. 초록 박스는 '보는 중', 회색 박스는 셈에서 뺀 얼굴입니다. Esc나 X로 닫습니다. 켜 둔 동안에는 카메라가 계속 켜집니다.
- **감시 간격**: 계속 / 5초 / 10초 / 30초. 고른 값은 저장됩니다.
- **알림**: Windows 알림 켜기·끄기. 저장됩니다.
- **설정 파일 열기**: `settings.json`을 메모장으로 엽니다.
- **일시정지**, **종료**

## 내 환경에 맞추기(settings.json)

처음 실행하면 같은 폴더에 `settings.json`이 생깁니다. 메뉴의 **설정 파일 열기**로 고치고 저장하면 실행 중에도 바로 반영됩니다.
잘못 쓰면 알림이 뜨고, 메뉴 맨 위에 오류가 표시되며, 고칠 때까지 이전 설정으로 계속 동작합니다.

| 항목 | 기본값 | 뜻 |
|---|---|---|
| `camera_index` | `0` | 카메라 번호. 외장 웹캠을 쓰면 `1`, `2`… |
| `scan_every_seconds` | `10` | 몇 초마다 확인할지. `0`이면 카메라를 계속 켜 둡니다(LED도 계속 켜짐) |
| `max_yaw_ratio` | `1.0` | 얼굴 방향 허용치. `0`은 카메라 정면이고, 클수록 옆으로 돌린 얼굴까지 '보는 중'으로 셉니다. `1.0`은 대략 60~65도입니다(추정) |
| `min_face_ratio` | `0.06` | 화면 너비 대비 이보다 작은(먼) 얼굴은 무시합니다. `0.06`은 일반 노트북 카메라 기준 약 2m입니다(추정). 낮추면 더 먼 사람까지 셉니다 |
| `score_threshold` | `0.8` | 얼굴 확신도(0~1). 낮추면 더 많이 잡지만 엉뚱한 것을 얼굴로 볼 수 있습니다 |
| `alert_frames` | `2` | 2명 이상이 몇 프레임 연속이어야 경고할지. 늘리면 지나가는 사람에 덜 반응합니다 |
| `notify` | `true` | Windows 알림 사용 여부 |
| `notify_cooldown_seconds` | `30` | 같은 알림을 다시 띄우기까지 최소 간격(초) |

### 방향 허용치(`max_yaw_ratio`) 맞추는 법

1. 평소 자세로 앉아 **카메라 화면 보기**를 켭니다. 얼굴 위 숫자가 방향 수치입니다.
2. 노트북 화면을 볼 때는 0 근처, 노트북 옆의 외부 모니터를 볼 때는 0.5~0.6 정도가 나올 수 있습니다(만든 사람 환경 기준).
3. 내 얼굴이 회색 박스로 나오면 `max_yaw_ratio`를 그 숫자보다 0.2쯤 크게 잡습니다.
4. 옆자리 사람이 자기 모니터를 보는데도 초록 박스로 잡혀 경고가 뜨면, 그 사람 숫자보다 조금 낮게 내립니다.

## 동작 방식과 한계

- 얼굴 검출은 OpenCV의 YuNet을 씁니다. 뒷모습은 얼굴로 잡지 않습니다.
- 시선이 아니라 **고개 방향**만 봅니다(코가 두 눈 가운데에서 벗어난 정도). 눈동자만 돌리는 것은 모릅니다.
- **누가 '나'인지는 모릅니다.** 사람 수만 세므로, 내가 자리를 비운 사이 다른 한 명만 보면 초록 1로 나옵니다.
- 벽에 걸린 사진·포스터 속 정면 얼굴도 사람으로 셀 수 있습니다.
- 간격 감시 중에는 확인과 확인 사이에 잠깐 보고 간 사람을 놓칠 수 있습니다.
- 노트북 카메라 LED는 대부분 하드웨어로 연결돼 있어 소프트웨어로 끌 수 없습니다. 간격을 늘려 켜져 있는 시간을 줄일 수 있을 뿐입니다.
- 주변 사람이 카메라에 찍히는 도구입니다. 회사나 공용 공간에서는 규정을 확인하고 쓰세요.
